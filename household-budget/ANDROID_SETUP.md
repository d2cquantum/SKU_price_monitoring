# 안드로이드 설정 가이드 (로컬 전용 방식)

대상: 우리카드 · 현대카드 · 삼성카드 · 우리은행 · 새마을금고
저장 방식: **로컬 전용** — 모든 데이터는 휴대폰 크롬 브라우저 안에만 저장되고 서버로 전송되지 않습니다.

> 카드사·은행 앱의 메뉴 이름과 알림 요금은 수시로 바뀝니다. 아래 경로가 다르면 앱 안 검색창에서 "알림", "이용내역", "거래내역"으로 찾으세요.

---

## 0. 먼저 알아둘 것

- **앱 주소는 하나로 정해서 쓰세요.** 브라우저 저장소는 주소(도메인)별로 따로라서, 미리보기 주소에서 넣은 데이터는 정식 주소에 보이지 않습니다.
  - PR 병합 후 정식 주소: `https://skupricemonitoring.netlify.app/household-budget/`
  - 병합 전 미리보기: `https://deploy-preview-1--skupricemonitoring.netlify.app/household-budget/` (시험용)
  - 미리보기에서 시험한 데이터를 옮기려면 **연동 탭 → 백업 내보내기 → 정식 주소에서 백업 불러오기**.
- **크롬의 "사이트 데이터 삭제"를 하면 가계부 데이터도 지워집니다.** 매주 백업하세요 (6번).

## 1. 앱 설치 (5분)

1. 안드로이드 **크롬**으로 위 주소를 엽니다.
2. 오른쪽 위 ⋮ 메뉴 → **앱 설치** (또는 "홈 화면에 추가").
3. 홈 화면에 생긴 **가계부** 아이콘으로 실행합니다. 이렇게 설치해야 2번의 "공유" 메뉴에 가계부가 나타납니다.
4. 처음 열면 예시 데이터가 보입니다. **내 데이터로 시작**을 두 번 눌러 예시를 지웁니다.
5. **연동 탭 → 설정**에서 월 예산을 입력합니다.

## 2. 카드 승인 문자 받기

공유 기능은 **문자(SMS)** 에서만 됩니다. 카드사 앱 푸시 알림은 다른 앱으로 공유할 수 없습니다.

| 기관 | 할 일 | 비고 |
|---|---|---|
| 우리카드 | 우리카드 앱 → 알림/결제알림 설정 → **문자(SMS) 승인알림** 신청 | 문자 알림은 월 소액 유료인 경우가 많음 |
| 현대카드 | 현대카드 앱 → 알림 설정 → **문자 결제알림** 선택 | 앱 푸시가 기본값이면 문자로 변경 |
| 삼성카드 | 삼성카드 앱 → 알림서비스 → **문자 이용알림** 신청 | |
| 우리은행 | 우리WON뱅킹 → 입출금 알림 → 문자 또는 앱 푸시 | 은행은 월 1회 엑셀로도 충분 |
| 새마을금고 | MG더뱅킹 → 입출금 알림 설정 | 은행은 월 1회 엑셀로도 충분 |

문자 비용이 부담되면 카드는 앱 푸시를 유지하고 **월 1회 엑셀(4번)만으로 운영**해도 됩니다. 이 경우 실시간 기록은 안 되지만 월말 집계는 동일합니다.

## 3. 문자 → 가계부로 보내기 (매일, 건당 3초)

**방법 A. 공유 (권장)**
1. 문자 앱에서 승인 문자를 **길게 누름** → **공유** → **가계부** 선택
2. 가계부가 열리며 문자가 채워지고 미리보기가 표시됨 → **가계부에 추가**

여러 문자를 한 번에 선택해서 공유해도 됩니다. 같은 문자를 두 번 보내도 한 번만 기록됩니다.

**방법 B. 복사·붙여넣기**
공유 메뉴가 없는 문자 앱이면 문자를 복사 → 가계부 **가져오기** 탭 → 입력칸에 붙여넣기 → **가계부에 추가**.

**방법 C. 자동화 (선택, 고급)**
MacroDroid 같은 자동화 앱으로 "문자 수신 시 → 웹사이트 열기"를 만들면 받을 때마다 자동 기록할 수 있습니다.
- 조건: 문자 수신, 내용에 `승인` 또는 `출금` 포함
- 동작: 웹사이트 열기 → `https://skupricemonitoring.netlify.app/household-budget/#auto=1&sms=` 뒤에 **문자 본문을 URL 인코딩해서** 붙임
- 주소의 `#` 뒷부분은 서버로 전송되지 않으므로 문자 내용이 밖으로 나가지 않습니다.
- 문자가 올 때마다 가계부 화면이 잠깐 열립니다. 앱마다 설정 방법이 달라 직접 시험이 필요합니다.

## 4. 월 1회 엑셀 올리기 (매월 초, 10분)

문자로 놓친 거래(앱 푸시만 온 결제, 해외결제, 자동이체)를 채우는 단계입니다. 문자로 이미 들어간 거래는 자동으로 중복 제외됩니다.

| 기관 | 내려받는 곳 (PC 홈페이지가 가장 확실) |
|---|---|
| 우리카드 | 홈페이지 → 이용내역 조회 → 엑셀 다운로드 |
| 현대카드 | 홈페이지 → 이용내역 → 엑셀 저장 |
| 삼성카드 | 홈페이지 → 이용내역 조회 → 엑셀 다운로드 |
| 우리은행 | 인터넷뱅킹 → 조회 → 거래내역조회 → 엑셀 저장 |
| 새마을금고 | MG더뱅킹 인터넷뱅킹 → 거래내역조회 → 엑셀 저장 |

1. PC에서 받은 파일을 휴대폰으로 옮깁니다 (카카오톡 "나와의 채팅", 구글 드라이브 등).
2. 가계부 **가져오기 → 엑셀·CSV** 에서 **어느 기관 파일인지 선택** → 파일 선택.
3. 결과에 "인식한 열"이 표시됩니다. "열을 찾지 못했습니다"가 나오면 그 메시지의 열 이름을 알려주세요. 맞춰 드립니다.

은행 엑셀의 **카드대금 출금**(예: 기재내용 "현대카드")은 지출이 아니라 **이체**로 자동 분류되어 이중 계상되지 않습니다.

## 5. 정리 (매주 5분)

- **홈 → 미분류 N건 정리**: 카테고리를 한 번 지정하면 같은 가맹점은 이후 자동 분류됩니다.
- **고정비 탭**: 보험·통신·관리비·대출이자를 등록하면 매달 출금 여부와 금액 변동을 표시합니다. "고정비 후보"에 반복 결제가 뜨면 **등록**.

## 6. 백업 (매주 1회)

1. **연동 탭 → 백업 내보내기** → `가계부-백업-날짜.json` 파일이 저장됩니다.
2. 구글 드라이브 등에 올려 보관합니다.
3. 휴대폰을 바꾸거나 데이터가 지워지면 **백업 불러오기**로 복원합니다.

## 7. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 공유 메뉴에 가계부가 없음 | 1번처럼 "앱 설치"로 설치했는지. 홈 화면 바로가기만 만든 경우 공유 대상이 되지 않음 |
| 문자가 "확인 필요"로 표시 | 금액이나 가맹점을 못 찾은 경우. 이름·카드번호를 가린 문자 원문을 알려주시면 파서를 맞춤 |
| 엑셀을 못 읽음 | .xls/.xlsx 읽기는 인터넷 연결이 필요(처음 한 번). 안 되면 엑셀에서 CSV로 저장해 올리기 |
| 데이터가 사라짐 | 다른 주소(미리보기 vs 정식)로 열었거나 브라우저 데이터를 지운 경우. 백업 불러오기 |
