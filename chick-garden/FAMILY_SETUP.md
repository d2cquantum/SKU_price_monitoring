# 가족 정원 설정하기 (Firebase · 구글 로그인)

병아리 정원을 가족이 **각자의 구글 계정**으로 로그인해서 **한 정원을 함께** 관리하도록 설정하는 방법입니다.
한 번만 설정하면 되고, 15분쯤 걸립니다. 비용은 무료 요금제(Spark)로 충분합니다.

> 설정 전에는 앱이 지금처럼 "이 휴대폰에만 저장"으로 동작합니다. 설정해도 로그인하지 않으면 그대로 혼자 쓸 수 있어요.

## 1. Firebase 프로젝트 만들기
1. 컴퓨터에서 <https://console.firebase.google.com> 에 구글 계정으로 접속
2. **프로젝트 추가** → 이름 예: `chick-garden` → Google 애널리틱스는 **사용 안 함**으로 해도 됩니다 → 만들기
3. 요금제는 기본 **Spark(무료)** 그대로 둡니다. (사진도 Firestore에 저장하도록 만들어서 Storage·유료 요금제가 필요 없어요)

## 2. 구글 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **Google** → 사용 설정 → 프로젝트 지원 이메일 선택 → 저장
3. **설정** 탭 → **승인된 도메인** → **도메인 추가**
   - `chick-garden.netlify.app` (병아리 정원 사이트 주소. Netlify에서 바꿨다면 그 주소)
   - 미리보기 주소에서도 로그인해 보려면 그 주소도 하나씩 추가 (예: `deploy-preview-8--chick-garden.netlify.app`)
4. **아이폰용 설정 (한 번만):** <https://console.cloud.google.com/apis/credentials?project=chick-garden> 접속
   (Firebase와 같은 구글 계정, 프로젝트 `chick-garden`)
   - **OAuth 2.0 클라이언트 ID** 목록에서 **Web client (auto created by Google Service)** 클릭
   - **승인된 JavaScript 원본**에 `https://chick-garden.netlify.app` 추가
   - **승인된 리디렉션 URI**에 `https://chick-garden.netlify.app/__/auth/handler` 추가 → **저장** (적용까지 5분~몇 시간 걸릴 수 있어요)
   - 왜 필요한가요? 아이폰(사파리)은 다른 사이트(`firebaseapp.com`)의 로그인 정보를 막아서, 아이폰에서는 로그인 화면을 우리 사이트 주소(`/__/auth`)로 띄웁니다. 그 주소를 구글에 "허용된 로그인 복귀 주소"로 알려 주는 단계예요.

## 3. 데이터베이스(Firestore) 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: **asia-northeast3 (서울)** → 다음
3. **프로덕션 모드에서 시작** → 만들기
4. **규칙** 탭을 열고, 저장소의 `chick-garden/firestore.rules` 내용을 **전부** 복사해 붙여넣은 뒤 **게시**
   - 이 규칙 덕분에 가족 정원 구성원만 식물·기록·사진을 볼 수 있고, 초대 코드가 있어야만 들어올 수 있습니다.

## 4. 웹 앱 등록하고 설정값 복사
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정 → 일반** → 아래쪽 **내 앱**에서 웹 아이콘 `</>` 클릭
2. 앱 닉네임 `병아리 정원` → (Firebase Hosting은 체크하지 않음) → 앱 등록
3. 화면에 나오는 `firebaseConfig` 중 **apiKey, authDomain, projectId, appId** 네 줄을 복사
4. 저장소의 `chick-garden/firebase-config.js`에서 마지막 줄을 아래처럼 바꿔 커밋하세요. 값을 Claude에게 알려 주면 대신 반영해 드려요.

```js
window.CG_FIREBASE = {
  apiKey: "AIza...",
  authDomain: "chick-garden-xxxx.firebaseapp.com",
  projectId: "chick-garden-xxxx",
  appId: "1:1234567890:web:abcdef123456"
};
```

> 이 값들은 앱을 구분하는 **공개 식별자**라서 저장소나 사이트에 올라가도 괜찮습니다(비밀번호가 아님). 데이터는 3단계의 보안 규칙이 지킵니다.
> 더 단단히 하고 싶으면 Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → 해당 브라우저 키에 "웹사이트 제한"으로 사이트 주소만 허용할 수 있어요(선택).

## 5. 휴대폰에서 가족 정원 시작하기
**먼저 시작하는 사람 (예: 남편)**
1. 휴대폰 크롬으로 `https://chick-garden.netlify.app` 열기 (설치해 둔 앱이면 앱으로)
2. **설정 → 가족 정원 → Google로 로그인**
3. 이름(예: 우리집 정원)을 적고 **만들기** → 이 휴대폰에 있던 식물·기록·사진이 가족 정원으로 올라갑니다
4. **가족 초대하기 → 초대 링크 보내기** → 카카오톡 등으로 배우자에게 전송 (초대 코드는 7일 동안 유효)

**초대받은 사람 (예: 아내)**
1. 받은 링크를 크롬으로 열기 → **Google로 로그인**
   - **아이폰:** 사파리에서 **홈 화면에 추가**로 앱을 먼저 설치하고, 설치한 앱의 **설정 → 초대 코드로 들어가기**에 코드 6자리를 넣은 뒤 로그인하세요. 아이폰은 사파리와 설치한 앱의 저장 공간이 따로예요. 로그인하면 구글 화면으로 이동했다가 앱으로 돌아와요.
2. 자기 휴대폰에만 있던 식물이 있으면 "합칠까요?"라고 물어봐요. 합치면 둘의 식물이 한 정원에 모입니다
3. 끝! 이제 한 사람이 캘린더에서 닉네임을 누르면 다른 사람 화면에도 바로 "물 줌"으로 바뀌고, "지은님이 몬순이에 물을 줬어요" 같은 알림이 떠요

## 알아 두면 좋은 것
- **누가 했는지:** 기록마다 한 사람의 이름이 붙어요 (일간 보기, 관리 일지).
- **동시에 눌러도 한 번:** 같은 식물을 같은 날 둘이 동시에 "물 줬어요" 해도 기록은 한 건이에요.
- **오프라인:** 인터넷이 없을 때 누른 기록은 휴대폰에 모아 두었다가 연결되면 자동으로 올라가요. 설정의 초록 점(동기화됨)/노란 점(오프라인)으로 확인할 수 있어요.
- **휴대폰을 바꾸면:** 새 휴대폰에서 같은 구글 계정으로 로그인하면 가족 정원에 자동으로 다시 연결돼요.
- **나가기·로그아웃:** 가족 정원의 기록은 그대로 남고, 그 휴대폰만 가족 정원에 들어가기 전 데이터로 돌아가요.
- **무료 한도:** Firestore 무료 요금제는 저장 1GB, 하루 읽기 5만·쓰기 2만 회예요. 사진은 한 장에 0.1~0.3MB 정도라 수천 장까지 괜찮아요.

## 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| 로그인 창이 바로 닫히고 `auth/unauthorized-domain` | 2단계 3번 **승인된 도메인**에 지금 주소가 있는지 |
| 아이폰에서 구글 화면에 `오류 400: redirect_uri_mismatch` | 2단계 4번 **승인된 리디렉션 URI**를 추가했는지 (저장 후 몇 분 기다리기) |
| 아이폰에서 로그인하고 돌아왔는데 그대로 로그아웃 상태 | 설치한 앱을 완전히 닫았다 다시 열기 → 그래도 안 되면 `https://chick-garden.netlify.app/__/auth/handler`가 Netlify 404가 아닌지 확인 |
| 로그인 창이 안 열림 | 크롬 팝업 차단 해제, 또는 설치된 앱 대신 크롬 브라우저에서 한 번 로그인 |
| "접근할 수 없어요" / `permission-denied` | 3단계 4번 **규칙**을 게시했는지, 초대 코드가 7일 안인지 |
| 설정에 "Firebase 설정이 필요해요"가 계속 보임 | `firebase-config.js`가 바뀐 채로 배포됐는지, 앱을 완전히 닫았다 다시 열기 |
